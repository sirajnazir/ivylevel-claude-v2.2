## Overview

This document will contain the evaluation rationale for choosing Letta over other multi-agent platforms.

## Platforms Evaluated

| Platform | Strengths | Weaknesses | IvyLevel Fit |
|----------|-----------|------------|--------------|
| **Letta** | Persistent memory, A2A communication | Newer, less ecosystem | RECOMMENDED |
| LangGraph | Mature, flexible | No built-in memory persistence | Good |
| Agno | Simple, lightweight | Limited features | Limited |
| AutoGen | Microsoft backed | Complex setup | Moderate |
| CrewAI | Easy setup | Less flexible | Limited |

## Why Letta

1. **Persistent Memory Blocks** - Critical for coaching continuity
2. **Agent-to-Agent Communication** - Built-in multi-agent patterns
3. **Human-in-the-Loop** - Native HITL support
4. **Deployment Flexibility** - Cloud or self-hosted

## Key Decision Factors

- Student coaching requires memory persistence across sessions
- Multi-agent coordination (Orchestrator → Specialists)
- HITL approval for critical decisions
- Integration with existing IvyLevel infrastructure
